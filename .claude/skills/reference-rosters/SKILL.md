## What still needs a search

- **Anything after the 3 November 2026 midterms.** Districts, chairs and majorities all move. Re-verify this whole file in November.
- **Committee ranking members** not listed above.
- **FERC commissioner terms and any new nominations.** Seats turn over mid-term.
- **State legislative districts outside the three listed.** Verify each new one once, then add it here.
- **Anyone joining the prototype for the first time.** Verify once, then add the row so nobody searches for it twice.

## How to maintain this

When a new person enters the prototype, verify the facts once against a primary source, write the row here, then use it. When the file and a new search disagree, the search wins and the file gets corrected with a new verified date at the top.
